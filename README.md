# Pix aproximando os celulares · protótipo

Protótipo em código do momento da aproximação (estudo de UX, v2). Abra a página no computador: os dois celulares aparecem lado a lado. Arraste um celular até o outro, ou use "Aproximar os celulares", e depois toque e segure "Pagar".

- Confirmação: `?confirmar=b` (padrão), `a` ou `d`.
- Par de celulares: `?nivel=direcao` (padrão), `distancia` ou `contato`.
- Num celular só: `?papel=antonio&solo=1` ou `?papel=cristina&solo=1`.

Dados fictícios. Não é um produto do Mercado Pago.
